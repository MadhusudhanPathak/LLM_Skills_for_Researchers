# Assumptions and inferential gaps

Use this move to find what the work takes for granted, and the unstated bridges between its steps. It applies in every category: arguments, theories, designs, specifications and studies all rest on assumptions that are rarely written down.

## Use when

- The work seems to succeed too easily.
- A transition between steps feels like a jump.
- The researcher's position and an opponent's seem to share premises nobody has examined.
- Stage 3 of the arc.

## 1. Where to look

Search each place separately. Assumptions in different places need different kinds of support.

| Place | Typical assumptions |
|---|---|
| Conceptual | How terms are defined; which categories exist; where boundaries lie |
| Metaphysical | What exists; what can exist; what depends on what |
| Epistemic | What can be known, by whom, with what access; what counts as evidence |
| Normative | What matters; whose interests count; what is acceptable |
| Methodological | Which methods are legitimate; what a valid test or proof looks like |
| Empirical | How people, organisations, organisms, systems or materials behave |
| Technical | How components behave; what the environment provides; resource limits |
| Statistical | Independence, distributions, sampling, stability |
| Scope | Which cases, populations, settings and time spans the claim covers |
| Institutional and practical | Adoption, incentives, funding, implementation, compliance |

## 2. Questions for each assumption

- Is it stated or unstated?
- Is it necessary for the conclusion, or could a weaker assumption do the same work?
- Is it defended anywhere, independently of the conclusion?
- Is it shared by the intended opponent or audience, or does it need defending to them?
- What follows if it is denied, weakened, or replaced?
- How would you check whether it holds?

## 3. Starting points versus load-bearing assumptions

Not every background commitment is a defect. Separate:

- **unavoidable starting points**, which any work in the area must make and which the audience shares;
- **contestable load-bearing assumptions**, which the conclusion depends on and which a reasonable critic could reject.

Spend the session on the second kind.

## 4. Inferential gaps and bridge premises

- What licenses the move from this claim to the next?
- State the missing bridge premise explicitly. Is it analytic (true by meaning) or substantive (a claim about the world, a value, or a method)?
- Does the bridge need empirical support? Does it contain a modal, causal or normative assumption?
- Does it hold universally, or only under conditions that should be stated?
- Would the intended opponent accept it, or does it restate the conclusion?

Ask for two candidate bridges: one stronger and less defensible, one narrower and more plausible. Compare what each costs and what each lets the argument conclude.

## 5. Ranking

Rank the assumptions found on three dimensions:

- **Dependence**: how much of the conclusion falls if this assumption falls;
- **Contestability**: how likely a reasonable critic is to reject it;
- **Checkability**: how cheaply it can be tested or defended.

Then assign each to a tier:

- **Dealbreaker**: if false, the work produces nothing. Check before committing further, using the cheapest test available (a pilot, a calculation, a source check, an email to a data owner, a conversation with a supervisor).
- **Important**: if false, the design or argument changes, but the work survives.
- **Secondary**: affects extensions only. Leave until the dealbreakers hold.

## 6. The smallest set

- What is the smallest set of assumptions on which the conclusion depends?
- If you could defend only one of them properly, which would you choose, and why?
- Which assumption, if false, would you most want not to know about?

## Watch for

- Labelling an assumption false because it is unstated. Unstated is not the same as unjustified.
- Listing every background commitment. The value is in the ranking, not the length.
- Assumptions hidden in the choice of examples, cases, data or baselines.
- Assumptions shared by the researcher and all their critics, which therefore never get examined.

## Artefact

**Assumption register**: each assumption with its place, whether it is stated, its dependence, contestability and checkability, its tier, and the cheapest check. Ordered by priority, dealbreakers first.
